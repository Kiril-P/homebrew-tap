# Kiril-P/homebrew-tap

Homebrew casks for [Merge Goblin](https://github.com/Kiril-P/merge-goblin), the menu bar app
that reviews GitHub pull requests with your AI subscription.

```bash
brew install --cask Kiril-P/tap/merge-goblin
```

Builds are not notarised yet: on first launch, open **System Settings › Privacy & Security**
and click **Open Anyway** next to Merge Goblin.

`Casks/merge-goblin.rb` is generated by the Merge Goblin release workflow and copied here
with `scripts/update-tap.sh` in that repo. Do not edit it by hand.
