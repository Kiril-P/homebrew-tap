# Kiril-P/homebrew-tap

Homebrew casks for:

- [Merge Goblin](https://github.com/Kiril-P/merge-goblin), the menu bar app that reviews
  GitHub pull requests with your AI subscription.
- [Contrail](https://github.com/Kiril-P/contrail), a glowing trail that follows your cursor,
  for demos and screen recordings.

```bash
brew install --cask Kiril-P/tap/merge-goblin
brew install --cask Kiril-P/tap/contrail
```

Builds are not notarised yet: on first launch, open **System Settings › Privacy & Security**
and click **Open Anyway** next to the app. Contrail updates itself after that.

Each cask is generated by its app's release workflow and copied here with that repo's
`scripts/update-tap.sh`. Do not edit them by hand.
